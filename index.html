AYUDA

Preguntas frecuentes

¿Cómo sé si mi número está disponible?

Usa el buscador de números. Los números vendidos aparecen bloqueados y los disponibles se pueden seleccionar.

¿Cuándo queda confirmado mi boleto?

En la versión final, el boleto se confirma únicamente cuando el sistema recibe y valida el pago mediante la pasarela o el proceso autorizado.

¿Cómo se elige al ganador?

La plataforma está diseñada para ejecutar un sorteo electrónico únicamente entre boletos válidos y pagados, dejando un registro del resultado.

¿Puedo comprar varios números?

Sí. Puedes elegirlos uno por uno o usar los botones rápidos para seleccionar varios números disponibles.

Estado actual: esta página ya está online, pero el checkout y los pagos siguen en modo demostración. Antes de aceptar dinero real se conectarán backend, base de datos, autenticación, confirmación de pagos y los controles legales/operativos correspondientes.
