# RIFA RD PRO — prototipo web

Prototipo estático y responsive para una plataforma de rifas de motores, scooters y vehículos en República Dominicana.

## Archivos
- `index.html`: página pública
- `admin.html`: panel administrador demo
- `styles.css`: estilos
- `app.js`: selección de boletos y lógica demo

## Probar localmente
Abre `index.html` en tu navegador.

## Publicar con GitHub Pages
1. En **Settings → Pages**, selecciona la rama `main` y carpeta `/root`.
2. GitHub mostrará la URL pública.

## Importante antes de vender boletos reales
Este prototipo no procesa dinero real ni sustituye un backend. Para producción se requiere al menos:
- backend seguro y base de datos transaccional;
- autenticación/2FA para administradores;
- integración aprobada con pasarela de pago;
- webhooks para confirmar pagos;
- bloqueo transaccional de números;
- sorteo en servidor con RNG criptográfico y auditoría inmutable;
- cumplimiento legal y regulatorio aplicable en República Dominicana.
